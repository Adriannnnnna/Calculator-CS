# Calculator-CS

Aplicație consolă în C# care efectuează cele 4 operații aritmetice: adunare (+), scădere (-), înmulțire (*) și împărțire (/).

## Ce face programul
- cere primul număr, operația și al doilea număr;
- afișează rezultatul, de exemplu `Rezultat: 12 * 4 = 48`;
- verifică împărțirea la zero și afișează un mesaj de eroare;
- acceptă numere zecimale scrise cu virgulă sau cu punct (2,5 sau 2.5);
- se oprește când apăsați Enter la „Primul numar”.

## Cum se rulează
1. Clonați repository-ul:
   ```
   git clone https://github.com/Adriannnnnna/Calculator-CS.git
   ```
2. Intrați în folder: `cd Calculator-CS`
3. Rulați comanda: `dotnet run`

Este nevoie de .NET SDK 8.0 sau mai nou.

## Exemplu
```
=== Calculator-CS ===
Primul numar: 12
Operatia (+, -, *, /): /
Al doilea numar: 0
Eroare: impartirea la zero este imposibila!

Primul numar: 12
Operatia (+, -, *, /): *
Al doilea numar: 4
Rezultat: 12 * 4 = 48
```
